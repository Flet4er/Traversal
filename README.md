## Общие технические детали
Проект построен на строгой типизации C++. Вся логика взаимодействия игрока с окружением вынесена в отдельные классы UGameplayAbility и UAbilityTask. Это позволило изолировать сложную математику трейсов и расчета траекторий от основного цикла персонажа.

## Кастомные Ability Tasks
Для реализации бега по стене были созданы наследники UAbilityTask, которые:
- Выполняют проверку наличия стены каждый кадр (TickTask).
- Управляют вектором скорости (Velocity) напрямую, минуя стандартную физику трения, для достижения эффекта "прилипания" к стене.
- Корректно обрабатывают завершение задачи через делегаты, возвращая управление основному компоненту движения.

## Управление
- Перемещение - WASD
- Спринт - Shift
- Быстрая стойка - RMB
- Vault\Mantle - F
- прыжок - Space
